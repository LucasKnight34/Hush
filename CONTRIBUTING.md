# Contributing

Jira is the source of truth for planning: https://lucasknight336-1790873410738.atlassian.net/jira/software/projects/HUSH

## Branches

Branch names start with the Jira key, followed by a short description:

```
HUSH-123-short-description
```

## Commits

Commit messages start with the Jira key:

```
HUSH-123: Add reminder table
```

## Pull requests

Every change goes through a pull request into `main`. No direct pushes. Fill in the PR template and link the Jira ticket.

## Spikes and decisions

Spikes record their findings in Confluence. Decisions that come out of them are recorded in `docs/adr`.

## Cost

Development must cost $0. New services must stay free and be added to [docs/cost-plan.md](docs/cost-plan.md) before they are used.
