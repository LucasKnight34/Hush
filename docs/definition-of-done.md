# Definition of Ready and Definition of Done

## Definition of Ready

A story can be pulled into a sprint when:

- Acceptance criteria are written.
- Points are estimated.
- Dependencies are identified.
- The design task is done, if UI is involved.

## Definition of Done

A story is done when:

- Code is merged to main through CI.
- Unit and integration tests are passing.
- Acceptance criteria are met.
- It is deployed to dev.
- Sarah has accepted user-facing stories.
- Any decision worth explaining is captured in a decision record (`docs/adr`).
